# Flaggen-Quelle

Die SVG-Flaggen in diesem Ordner stammen aus dem Open-Source-Projekt
[flag-icons](https://github.com/lipis/flag-icons) von Panayiotis Lipiridis
(Version 7.5.0, Ordner `flags/4x3`), lizenziert unter der MIT-Lizenz
(siehe `LICENSE-flag-icons.txt`).

Es wurde nur die Teilmenge der Flaggen übernommen, die für die 60 Länder in
`data/countries.json` benötigt wird (Dateiname = ISO-3166-1-alpha-2-Code,
z. B. `de.svg` für Deutschland).
